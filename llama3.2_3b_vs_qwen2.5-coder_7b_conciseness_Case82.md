1. **Token Generation**: A fixed number of tokens are generated, which can be used to access and query data.
2. **Transaction Fees**: A transaction fee is applied to each query, which is used to fund the operation of the edge network.
3. **Token Distribution**: Tokens are distributed among users and devices, allowing for access to data and services.
